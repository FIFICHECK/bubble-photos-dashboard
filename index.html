📖 使用教學 & 注意事項

📌 基本流程

  • 每個 SKU 可以設定多個 Phases（階段），每個 Phase 有時間 + 相片 URL
  • 時間到就會自動經 MMS 換相
  • Cron 每 5 分鐘 check 一次

➕ 新增 SKU

  • 入 SKU ID（e.g. B0961005_S_4891609702053）
  • 撳 🔍 Fetch Name 自動拎 product name（optional）
  • 每個 Phase 入：Label / Photo URL / Time
  • 撳 💾 Save SKU 儲存 → 自動跳去 SKUs 列表

🖼️ 相片 URL

  • 要用 直接圖片連結（.jpg / .png / Google Drive CDN）
  • Google Drive: https://lh3.googleusercontent.com/d/{FILE_ID}
  • ❌ 唔好用 drive.google.com/file/d/...（HTML 頁面）

🗑️ 刪除

  • 單個刪除：撳 row 最右嘅 ✕ 掣
  • 批量刪除：Tick 左邊 checkbox → 撳頂部「🗑️ Delete Selected」
  • 📝 Log 頁面同樣支援單個/批量刪除

⚠️ 注意事項

  • MMS session 大約 2-3 分鐘 過期，script 會自動 relogin
  • 相片 click 可以 放大預覽，再 click 關閉
  • SKU ID 係 clickable link → 直接去 HKTVmall product page
  • 如果 save 時出 SHA error 會 auto retry 5 次
  • Dashboard 每 30 秒 auto refresh

📊 Status 狀態

  • ⏳ Pending = 未開始
  • 🟢 Active = 進行中
  • 🔵 Done = 全部 phases 完成
  • ❌ Fail = Upload 失敗
